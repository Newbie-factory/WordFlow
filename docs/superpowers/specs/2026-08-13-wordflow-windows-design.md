# WordFlow Windows 离线词汇学习器设计规格

状态：已完成设计会审，等待用户对书面规格作最终确认
日期：2026-08-13
项目根目录：`D:\baicizhan`

## 1. 产品定位

WordFlow 是一款面向 Windows 10 与 Windows 11 的个人离线雅思词汇学习器。它以低干扰的桌面悬浮卡作为日常入口，通过全局快捷键完成主动回忆反馈，并以本地 FSRS-6 调度复习。

产品首先服务单用户本机迭代；架构保留未来公开发布能力，但首版不包含账号、云同步、联网更新、社交排行、AI 在线生成或远程遥测。

### 1.1 核心目标

- 双击应用后，在主显示器右下角显示紧凑悬浮卡。
- 悬浮卡可拖到任意显示器的任意可见位置，并保持置顶。
- 用户可通过全局快捷键在不中断当前工作的情况下完成学习反馈。
- 全部词库、学习记录、算法状态、统计、皮肤与日志留在本机。
- 界面简洁、克制、高级；视觉参考 Apple 的留白与材质感，同时遵守 Windows 交互习惯。
- 提供可靠的数据备份、撤销、恢复和可解释的调度状态。

### 1.2 非目标

首版不实现：账号体系、多设备同步、服务器、广告、排行榜、好友系统、在线翻译、联网语音、在线 AI 例句、OCR、浏览器插件和跨平台版本。

## 2. 技术路线

### 2.1 选定方案

- UI：WPF + C# + XAML。
- 运行时：.NET 8 LTS，自包含 `win-x64` 发布。
- 架构：MVVM，UI、应用用例、领域模型与基础设施分层。
- 持久化：SQLite；词典数据与用户学习数据逻辑分离。
- 系统集成：Win32 全局快捷键、单实例、托盘、窗口置顶与显示器工作区检测。
- 安装：首版生成自包含安装包；正式发布前在干净系统验证安装、升级和卸载。

### 2.2 选择理由

WPF 在无边框置顶窗口、拖动、系统托盘、全局快捷键、多显示器和 Windows 10/11 兼容方面成熟。它能提供精细的 XAML 样式、动画、圆角、半透明与图片皮肤，又比 WinUI 3 更少依赖窗口桥接和部署组件。相较 Tauri/Electron，它不需要 WebView 运行时来承载核心 UI，常驻内存和系统行为更可控。

### 2.3 系统最低要求

- Windows 10 22H2 x64 或 Windows 11 x64。
- 支持 100%、125%、150%、200% DPI。
- .NET 由应用自包含，不要求用户预装运行时。
- Windows 10 的高级材质效果允许降级，但功能必须完整。

## 3. 窗口体系与应用生命周期

### 3.1 悬浮学习卡

- 默认出现在主显示器工作区右下角并避开任务栏。
- 无传统标题栏，圆角、阴影、可拖动，默认置顶。
- 信息层级固定为：单词、音标、简体中文释义、当日进度、操作提示。
- 音标必须位于单词正下方。
- 点击单词播放离线发音；点击卡片非操作区域打开详情或控制中心。
- 空白区域可拖动；窗口位置和所在显示器自动保存。
- 支持显示、隐藏与暂停置顶；全屏游戏、视频或演示时可自动暂时取消置顶，默认开启。
- 关闭悬浮卡只隐藏到托盘，不退出进程。

### 3.2 学习控制中心

按需打开的主窗口，包含：

- 今日学习：首页行动入口、当日新词、到期/逾期复习、预计时间和简要趋势。
- 词汇库：搜索、筛选、分层浏览和词条详情。
- 已斩词汇：搜索、分页、批量选择、取消斩、导出和恢复调度。
- 学习统计：保持率、复习量、连续学习、困难词和历史趋势。
- 设置：学习、快捷键、悬浮卡、皮肤、发音、数据与备份。

### 3.3 系统托盘

托盘菜单提供：

- 显示/隐藏悬浮卡。
- 暂停/恢复学习。
- 打开控制中心。
- 查看今日简要进度。
- 显式退出。

### 3.4 进程规则

- 应用为单实例。重复启动时唤醒已有实例，不创建第二个写数据库的进程。
- 首次启动展示简短引导，确认任务量、快捷键、发音和数据目录。
- 开机启动默认关闭，由用户选择开启。
- 显示器拔插、工作区或 DPI 改变时，窗口必须被修正回可见区域。

## 4. 视觉与交互设计

### 4.1 视觉语言

- 浅色中性底、低饱和蓝色主色、克制圆角和细腻阴影。
- 主要依靠留白、字号、字重和透明层级组织信息。
- 默认不使用鲜红数字制造焦虑；红色只表达确实的错误或破坏性风险。
- 无广告、无排行榜、不过度游戏化。
- Windows 11 可启用更高级材质；Windows 10 使用等价的半透明或纯色降级。
- 支持系统高对比度、减少动画与缩放设置。

### 4.2 悬浮卡已确认布局

- 采用紧凑横卡方向。
- 单词使用页面最高视觉权重。
- 音标单独占一行，位于单词之下。
- 中文释义位于音标之下。
- 底部展示 F1/F2/F3 操作和进度。
- `Shift+F3` 的“斩”操作在提示中可发现，但弱于日常三键。

### 4.3 控制中心首页

首页只回答三个问题：今天学多少、复习多少、进展如何。显示：

- 今日新词完成进度。
- 到期与逾期复习数量。
- 预计剩余学习时间。
- 连续学习、已掌握和已斩数量。
- 最近七天简要趋势。
- 需要关注的困难词。
- 一键继续学习。

详细分析留在统计页面，首页不堆叠全部指标。

### 5.2 选词口径

雅思官方没有发布唯一的完整 7000 词清单，因此产品不得宣称这 8,000 个词均为官方指定词汇。数据明确分层：

- `core`：5,040 个 ECDICT `ielts` 标签词。
- `foundation`：去重后增加 1,893 个 Oxford 核心词。
- `academic_extension`：增加 1,067 个带 TOEFL 标签且有中文释义和音标的高频学术词。

总数为 8,000 个不区分大小写的唯一词条，简体中文释义覆盖 8,000/8,000。界面允许按层学习，并展示来源口径。

### 5.3 词典字段

至少包含：单词、音标、英文释义、简体中文释义、词性、考试标签、词频、词形变化、层级和选择原因。用户学习状态不得写回只读词典数据。

## 6. 学习模型与 FSRS-6

### 6.1 调度模型

长期复习采用 FSRS-6。每个活动词条维护：

- Difficulty：难度。
- Stability：记忆稳定度。
- Retrievability：当前预计可回忆概率。
- 当前调度状态、上次复习时间和下次到期时间。

默认目标保持率为 90%，普通设置允许在 85%–95% 范围调整。新用户使用官方默认参数；积累至少约 400 条有效复习记录后，才允许在本机优化个性参数。优化默认只影响未来调度，不立即重排全部旧词。

### 6.2 快捷键语义

- `F1 不认识`：映射 FSRS `Again`，表示回忆失败。
- `F2 模糊`：映射 FSRS `Hard`，表示确实回忆出来但迟疑或费力。
- `F3 认识`：映射 FSRS `Good`，表示正常、清楚地回忆出来。
- `Shift+F3 斩`：业务状态变更，不映射 FSRS `Easy`，从活动调度队列移出。
- 撤销：默认仅在悬浮卡聚焦时使用 `Ctrl + Z`；全局撤销允许用户另行配置，避免破坏前台应用原有快捷键。

所有快捷键均可重绑。注册冲突必须被检测并明确提示，不得静默失效。快捷键按下后立即提交学习动作并切换下一词；通过视觉颜色和微动画提供短暂反馈，并防止长按连击。

### 6.3 新词与同日重学

- 每日队列先处理到期复习，再加入新词。
- 首次不认识的词采用可配置的同日重学步骤，默认约 10 分钟。
- 同日连续失败最多主动重学三次；之后转入困难词保护，不持续轰炸。
- 长期间隔完全由 FSRS 计算，不使用写死的 1、3、7、14 天表。

### 6.4 每日任务与逾期

- 默认每日 40 个新词。
- 默认每日复习软上限 120 个。
- 达到软上限后允许结束学习，不强迫清空无限积压。
- 逾期复习按预计可回忆率和调度风险排序，而不是只按逾期天数。
- 新词、复习词和软上限均可由用户调整。

### 6.5 困难词保护

连续遗忘的词进入困难词视图，系统优先提供音标、词根、例句、近义辨析或提示，而不是仅增加出现频率。首版记录反应时长用于统计和未来研究，但不直接修改 FSRS 间隔，避免把走神、离开电脑或切窗口误判为记忆困难。

## 7. 斩与取消斩

### 7.1 斩

- “斩”不删除词条、不清空历史、不伪造 FSRS 评分。
- 被斩词不再自动进入每日学习或复习队列。
- 保存斩词时间、斩词前的 FSRS 状态、触发方式和对应历史事件。
- `Shift+F3` 后提供短时撤销提示。

### 7.2 取消斩

- 用户可对单个词取消斩，也可批量操作。
- 取消斩后保留原难度、稳定度和完整历史。
- 系统根据斩前状态和经过时间估算当前可回忆率：低于目标保持率时加入下一次学习，否则按 FSRS 计算未来到期日。
- 用户可选择“按计划恢复”或“立即复习”。

### 7.3 已斩词汇页面

- 默认每页 100 条，可选 50、100、200，选择会被记住。
- 表格内容区独立纵向滚动，支持滚轮、触控板、拖动滚动条和 Page Up/Page Down。
- 表头与底部分页固定。
- 明确显示当前范围，例如“第 1–100 条，共 286 条”。
- 区分“本页全选”与“全部筛选结果全选”。
- 跨页批量取消斩需要二次确认，并提供短时撤销。

## 8. 自定义皮肤系统

### 8.1 范围

- 支持 PNG 图片。
- 可设置全局皮肤，也可分别覆盖悬浮卡和控制中心。
- 支持多个命名皮肤预设、实时预览和恢复默认。

### 8.2 图像行为

- 图片使用 WPF `Stretch=UniformToFill` 的语义：保持比例、居中或按焦点裁切、强制覆盖完整圆角区域。
- 不允许因适配窗口而非等比拉伸变形。
- 四个边角必须被图片覆盖，不允许白边或未绘制区域。
- 用户可调图片透明度、内容面板透明度、模糊强度、保护遮罩强度和焦点位置。
- 自动对比度保护默认开启；背景过亮或纹理复杂时增加局部遮罩，确保文本和按钮可读。

### 8.3 文件与性能

- 导入后将原始 PNG 复制到用户数据目录，避免外部源文件移动导致皮肤失效。
- 对超大图片生成适配缓存，降低启动解码和常驻内存成本。
- 无效、损坏、尺寸异常或超过安全上限的 PNG 必须提示错误并回退默认皮肤。

## 9. 离线发音

- 默认使用 Windows 本机离线语音合成。
- 检测并列出已安装的英文语音，允许选择英音或美音、语速和音量。
- 支持点击单词播放、可配置播放快捷键以及切换单词时自动播放。
- 若系统无可用英文语音，只关闭发音能力并提示安装 Windows 离线语言语音包，不发起网络请求。
- 架构允许未来导入合法的本地真人发音包，但首版不内置 8,000 个来源不明的录音。

## 10. 设置系统

设置分为四个主要入口：

- 学习：新词数量、复习软上限、目标保持率、同日重学、困难词保护和相近词打散。
- 快捷键：录制、冲突检测、启用/禁用和恢复默认。
- 悬浮卡与外观：尺寸、透明度、置顶、位置、自动隐藏、皮肤和动画。
- 数据与备份：数据目录、自动备份、导入、导出和恢复。

专业参数默认折叠。高级页可查看 FSRS 默认参数、个性化参数、优化日志、调度预览和诊断，但修改前必须解释影响并允许恢复历史快照。

## 11. 持久化与数据模型

### 11.1 数据库边界

- 只读词典库：内置词条及来源字段。
- 用户库：学习状态、FSRS 状态、到期日期、每日任务、设置、斩状态、事件日志和迁移版本。
- 皮肤与日志：用户数据目录中的文件，数据库只保存元数据和相对路径。

### 11.2 核心实体

- `VocabularyEntry`：词典词条。
- `CardState`：某词的 FSRS 和活动状态。
- `ReviewEvent`：不可变学习事件，含评分、时间、前后状态和撤销关联。
- `SlashEvent`：斩或取消斩事件及原因。
- `DailyPlan`：当天新词目标、复习软上限和完成情况。
- `AppSetting`：版本化设置。
- `SkinPreset`：图片、范围和渲染参数。
- `BackupRecord`：备份文件、哈希、版本和创建时间。

### 11.3 事务规则

F1/F2/F3、斩、取消斩和撤销均在单一 SQLite 事务中同时写入事件和当前快照。当前快照用于高效查询，事件日志用于审计、统计和重建。撤销通过反向事件实现，不物理删除既有历史。

## 12. 备份、恢复与隐私

- 每天首次启动创建滚动备份，默认保留最近 14 份。
- 支持手动完整备份、恢复和 JSON/CSV 导出。
- 数据库损坏时停止写入、保留原文件，并提供从最近有效备份恢复。
- 用户数据与安装目录分离；卸载默认不删除用户学习记录。
- 错误日志只写本机，提供打开日志目录入口。
- 运行时不发送遥测、学习记录、词条或皮肤图片。

## 13. 异常处理

- 快捷键冲突：指出具体动作和组合键，允许立即重绑。
- 单词发音失败：显示非阻断提示，学习继续。
- 皮肤失败：回退默认主题，保留问题文件供用户替换。
- 数据库写入失败：停止当前动作切换并显示恢复提示，避免 UI 显示成功但数据未提交。
- 强制结束或断电：已确认事务不得丢失；未按键的当前卡片无需记为学习事件。
- 数据迁移失败：回滚迁移，恢复升级前备份并阻止使用不兼容数据库继续写入。

## 14. 性能与可访问性目标

- 自包含发布在基准机器冷启动目标不超过 2 秒。
- 快捷键到视觉反馈和切词目标不超过 100ms。
- 空闲常驻内存目标低于 150MB。
- 8,000 词搜索和已斩 100 条分页应无可感知阻塞。
- 支持键盘完成全部核心操作。
- 正确响应系统 DPI、高对比度与减少动画设置。
- 关键控件具备屏幕阅读器名称、状态和值。

性能目标在明确基准机和测试方法前属于验收目标，不作为未经测试的完成声明。

## 15. 验证计划

### 15.1 自动测试

- 单元测试：FSRS 状态转换、目标保持率、同日重学、逾期排序、斩、取消斩和撤销。
- 属性测试：合法复习历史不得产生负间隔、无穷数、NaN、越界难度或倒退到期时间。
- 数据测试：8,000 个唯一词、8,000 个中文释义、CSV/SQLite 哈希、迁移前后进度一致。
- 集成测试：事件与当前快照的事务一致性、备份恢复、设置持久化和皮肤缓存。
- UI 自动测试：启动、拖动、置顶、隐藏、托盘恢复、100 条分页、皮肤导入和取消斩。

### 15.2 故障与兼容测试

- 写入期间强制结束进程。
- 对数据库副本制造损坏并验证恢复流程。
- 快捷键与常见应用组合键冲突。
- Windows 10 22H2 与 Windows 11 干净虚拟机。
- 100%、125%、150%、200% DPI。
- 单屏、双屏、拔插显示器和任务栏不同位置。
- 没有预装 .NET、没有英文语音、皮肤 PNG 无效和用户数据只读等条件。

### 15.3 算法验证

- 使用确定性复习历史回放，核对 FSRS 输出。
- 记录预测可回忆概率与实际成功率，生成校准图和分桶误差。
- 个性化前后比较 log loss 或同等概率预测指标，不以“复习次数少”单独判定更优。
- 目标保持率调整不得隐式污染评分历史。
- 不对产品宣传“绝对最优算法”；FSRS 是当前选定且可验证的成熟实现。

## 16. 交付阶段

设计拆为以下实施阶段，每阶段均要求测试通过后再进入下一阶段：
